This adapter is intentionally UI-only and contains no persistence or sync logic. The consuming ClassRecordWorkspace should pass only row-local evidence already returned by LearnerScoreApplicationService: `updatedAt`, current row error state, and current saving state. Removal of the legacy `formatSavedTime` helper and `Saved HH:MM` rendering belongs in the same bounded integration PR once the workspace edit is applied; no service or domain behavior should change.

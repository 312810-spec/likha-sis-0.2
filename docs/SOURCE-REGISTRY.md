| Google Stitch (`stitch.withgoogle.com`), an AI text/image-to-UI design generator, successor to the acquired Galileo AI, announced at Google I/O 2025 | Candidate PILOT tool for AI-assisted visual exploration during UI work, per a user-directed evaluation request | **REJECTED FOR NOW** (not installed, no credentials created, no data ever submitted) | An independent research agent dispatch hit this project's recurring agent-resume/retrieval failure (documented since M7) on both the initial attempt and one permitted retry — no findings text recoverable either time; self-conducted research (`WebSearch`, direct site fetch blocked by this session's egress proxy) substituted. (6) no credible neutral (non-affiliate-blog) source was found evaluating output quality specifically for accessibility (WCAG) or for maintaining genuine functional parity across a density-adjustable multi-mode interface (this project's Efficient/Comfortable/Guided requirement) — the exact qualities most relevant here; (7) this project already has a working, WCAG-contrast-verified, three-mode-parity design system ("Calm Civic Classroom," ADR-0030/0031/0032) built and shipped across three milestones without any AI design tool, so no evidenced gap exists that Stitch would close. **Verdict**: keep doing UI design directly through Claude Code with the existing design system, per this evaluation's own stated fallback criteria (adds friction via unofficial-only integration; real privacy-posture caveats even for synthetic data; architecture conflict via Tailwind-only export; unproven on the two qualities — accessibility and mode-parity — that matter most here). Revisit only if Google ships an official, audited API/MCP path with a clear non-training data policy and a code-export target that doesn't require Tailwind. |

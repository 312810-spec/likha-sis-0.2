# Source Registry

Every third-party source (tool, library, pattern, dataset, reference)
actually adopted or evaluated. Not browsing history — only what was
decided. In a research project this doubles as the citation ledger.

Tags: **ADOPT** (in use) · **PILOT** (trial, time-boxed) ·
**REFERENCE** (consulted, not adopted) · **REJECT** (evaluated, ruled
out — record why).

| Source           | Purpose                         | Tag   | Provenance checked                    | Network / telemetry               | Licence   | Switch / exit condition                 | Notes      |

| [name + version] | [what it does for this project] | ADOPT | [official docs / repo / release info] | [none / install-only / always-on] | [licence] | [what would make us drop or replace it] | [evidence] |

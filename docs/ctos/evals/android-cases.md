# Android cases

Android remains unsupported as a release claim until these are executed.

## AN-001 — Keystore create/reopen
Create protected database key through Android Keystore, reopen after process restart.

## AN-002 — Offline process death
Attendance/quick-score local work survives Android process death and reopen.

## AN-003 — Signed upgrade
A signed upgrade preserves encrypted data and key access.

## AN-004 — Document URI failure
Import/export staging handles revoked provider permission or unavailable document URI without data loss.

## AN-005 — Native compatibility
Required native libraries satisfy target Android/16 KiB compatibility requirements.

## AN-006 — Build and runtime
A real APK/AAB is produced as applicable and core companion flow is exercised on emulator/device.

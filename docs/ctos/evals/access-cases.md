# Access/session cases

## AC-001 — Account switch

Switching account clears prior class/school context before new authorized data renders.

## AC-002 — Spoofed/stale identifier

A teacher cannot gain work access by supplying a class/learner ID outside trusted assignments.

## AC-003 — Reassignment with pending work

Reassignment/revocation does not silently discard locally pending teacher work; handover state is explicit.

## AC-004 — Adviser versus subject scope

Advisory attendance and subject-class access remain distinct.

## AC-005 — Stale async response

A response from a prior account/class cannot overwrite the current session context.

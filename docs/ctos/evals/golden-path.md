# Golden-path cases

## GP-001 — Open next authorized class

Given a teacher with one current/next scheduled authorized class, Today opens that class in no more than two interactions and preserves section/subject/year/term context.

## GP-002 — Offline known context

Given a last-confirmed authorized assignment and no network, the teacher can open the class, record supported local work and see that it is saved locally but not yet transferred.

## GP-003 — No class today

Given no scheduled class, Today does not fabricate a next class and instead surfaces only real authorized pending work.

## GP-004 — Returned review

A returned report/form appears as an actionable exception with its class/report context and does not mutate the prior issued snapshot.

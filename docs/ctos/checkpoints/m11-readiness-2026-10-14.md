## Investigation and outcome contract

Existing report-card CSV exports already retain missing learners, identify provisional
grades and return field disclosures. They do not provide a full-period read-only
preparation preview, reviewed/issued snapshot lifecycle or amendment chain. Current
workspace grade display covers the selected assessment item's roster and is not
proof of full-period report readiness. Reuse the trusted period-range roster and
grade computation rather than deriving readiness from that narrower UI list.

The native `preview_class_record_report_card` command derives session actor/school,
then requires either an exact section/subject teaching assignment or same-school
School Head role. Missing/foreign records return no preview; same-school unassigned
teachers are refused. The read model carries class/year/period/pinned weight-policy
identity and a native check timestamp, all eligible period learners, missing vs
provisional vs complete computed-grade counts, per-learner explanations, missing
LRN flags and the existing CSV disclosure. Explicit official fidelity stays
`not_verified`; no readiness count is a professional approval or finality assertion.

This is a native foundation only: no teacher-facing preview wired yet, no file,
schema migration, data write, official-form issuance or lifecycle transition. SF8
stays inactive. Existing exports and their permission semantics are not widened.
M10 remains incomplete: declared source scope/integrity and teacher-asserted draft
review are not official curriculum/cohort approval or verified live AI acceptance.
Those dependencies remain parked while independent M11 development continues.

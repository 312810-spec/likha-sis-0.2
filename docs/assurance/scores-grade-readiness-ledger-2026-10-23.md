## Evidence → mechanism → counterexample

The baseline added four consequential cases and returned4 FAIL/118 PASS. The bulk-grade handler allowed reads during a dispatched score write; existing grade cells could still display an older number while that learner's score was unresolved. A late grade reply was similarly exposed during the save. Saved-only/unsaved-work explanation existed in the separate reporting-preview panel but not beside term grades in every mode.

Selected mechanism: block explicit bulk grade reads using the synchronous existing write-in-flight ref; render a waiting message instead of a saving learner's grade; label saved-only evidence and current-item pending work beside the action/results. Retain other learners' evidence and all draft input. No optimistic grade, grade formula rewrite, automatic score save, write replay, or new component dependency. A read started before saving is invalidated by the existing per-learner generation at write dispatch. The affected cell remains pending until settlement; confirmed saves retain current-generation refresh. Null/exception save outcomes mark an already-requested grade unconfirmed until a fresh read succeeds. Failed saves retain drafts/errors/reasons and allow explicit read retry against saved records, without a score replay. Old roster/learner/grade-context guards remain unchanged.

Native source inspection: TauriLearnerScoreRepository invokes compute_learner_term_grade with canonical classRecordId/learnerId; the inspected compute command calls require_active_school_scope, whereas score writes/history call the separate item-access guard. It does not itself call an assignment-access guard. This UI repair changes no authorization boundary and does not establish assignment-level authorization. Rust grading_computation::compute_term_grade resolves the class record's own policy and category scores. No UI recomputation or unsaved input enters that read. Browser fixture percentages are explicitly synthetic, not proof of native DepEd computation, official applicability or installed persistence.
